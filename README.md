# ☕ Cafe Management System

A simple Python console-based Cafe Management System that allows users to order food items from a menu and calculates the total bill.

## 📌 Features

- 📋 Displays the cafe menu
- 🍕 Order food items
- ➕ Add another item to the order
- 💰 Calculates the total bill
- ❌ Handles unavailable menu items

## 🛠️ Technologies Used

- Python 3

## 📂 Project Structure

```
cafe_Management/
│── cafe management.py
│── README.md
```

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/riddhideshmukh15/cafe_Management.git
```

2. Open the project folder:

```bash
cd cafe_Management
```

3. Run the program:

```bash
python "cafe management.py"
```
